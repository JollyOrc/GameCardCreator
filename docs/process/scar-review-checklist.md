# Step 0 — SCAR review

Read `scars/README.md` and every SCAR file under `scars/`, then check the new
instructions or user story against the Prevention list of every SCAR, using
the shared gate table `scars/GATES.md`. The sibling plugins keep a long
question list in their own checklist; this project starts from the SCARs
themselves and adds questions here when a SCAR review finds one worth keeping.
