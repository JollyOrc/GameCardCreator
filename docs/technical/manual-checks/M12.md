# M12 — The UI standard in Obsidian: run dialog, entry points, settings in sections (US-013 AC-14)

Part of the [manual checks](../manual-checks.md).

**When:** after ticket #56 on a test build (#57); again after any change to the run dialog, the entry points,
the settings tab's sections or the notices.

**Needs:** Obsidian desktop (the author's default environment: M1 MacBook, macOS 27.0.1, Obsidian 1.15.0).
Prepared by the developer (SCAR-012, SCAR-018) in the scratch vault of Obsidian2Typst
(`~/Documents/Obsidian2Typst/spikes/typst-wasm/scratch-vault`):

- the test build **`0.7.0-m12.1`** (installed by `npm run install:scratch`, the installed files equal to the
  fresh build by checksum: `main.js` `3d14305f…`; built from commit `edb5a95`; no diagnosis code), enabled in
  the plugin list;
- invented notes (SCAR-035, `spikes/m12-ui/generate-notes.mjs`): `M12 Skills` (*Arrow Rain*, *Parry Drill*,
  *Reed Sweep*, and in `Sub` *Feint Step*, *Low Guard*), `M12 Spells` (*Ember Mote*, *Stone Skin*, *Thin
  Breeze*), `M12 Notes` (*Loose Idea*, *Session Log*: no card kind);
- the plugin's `data.json`: kind rules `M12 Skills` skill, `M12 Spells` spell; output folder `M12 Out` in the
  vault (empty); no saved selection; everything else at its default.

The vault's other notes (Obsidian2Typst's) have no card kind: the tree shows them greyed.

The starting state is `spikes/m12-before.txt` (315 files, `workspace.json` left out; all OK before any
change); the `.obsidian` folder is in `spikes/m12-state-backup/files/` (15 files, all OK); the state after
the preparation is `spikes/m12-handover.txt` (329 files: 10 notes and the plugin's 4 files added, the plugin
list changed, nothing removed). Obsidian was not running during the preparation: **start Obsidian; it opens
the scratch vault**. The developer waits for the tester's "go" after each block.

**Expected version:** Game Card Creator `0.7.0-m12.1` (Settings, Community plugins). If it differs, stop.

**Expected values** come from a rehearsal in Node with the plugin's runner and selection functions on these
notes (`spikes/m12-ui/rehearse.ts`): Select all gives 8 cards in the order Arrow Rain, Parry Drill, Reed
Sweep, Feint Step, Low Guard, Ember Mote, Stone Skin, Thin Breeze, 1 page, 0 warnings, `Cards cards.pdf`
22 002 bytes; the three spells alone give 3 cards, 16 742 bytes. Earlier checks (M07, M10) had the same bytes
in Obsidian as in their rehearsals. **Not assumed:** the look of the tab and the dialog, focus, scrolling (a
fake DOM cannot show them; that is what this check is for).

## Decided before the run (SCAR-032)

Each step passes when Obsidian shows what the step says. A step that differs is a finding: noted with what
was seen, fixed in its ticket, and re-checked in a later test build. AC-14 is met when every step passes
(step 18 is optional: it needs an input method with composition).

## Steps

**Block A — the build**

1. Settings, Community plugins: **Game Card Creator `0.7.0-m12.1`**.

**Block B — the settings tab (AC-7 to AC-10)**

2. Settings, **Game Card Creator**. **Expected:** no large heading with the plugin's name; a first row with
   the link `Help: the README` and a bug icon on the right; the status line `Ready: 2 kind rules, output
   folder …/M12 Out`; then five sections, each with a chevron, a heading and a grey description: *Output*,
   *Which note is which card*, *Note properties*, *Page and text size*, *Titles*, with a thin line between
   them. **Only *Output* is open.**
3. Open *Page and text size* (click its heading). Set **Card width** to `10`, press Enter. **Expected:** a red
   message under the field; the status line changes to `Not ready:` with the problem. Close the settings
   window and open it again on Game Card Creator: **now *Page and text size* is the open section.** Set Card
   width back to `62`, Enter: the status line is `Ready: …` again.
4. Open *Titles*. **Expected:** three rows *Skill titles*, *Spell titles*, *Creature titles*, each with the
   description `Equal title bars` and a switch, **no gear**. Turn on the switch of *Skill titles*
   (without closing the tab). **Expected:** a gear appears in that row. Click it: a small window *Skill
   titles* with **Title size** and **Smallest title size**. Set Title size to `13`, Enter, then press
   Escape. Turn the switch off and on again, open the gear: Title size still `13`.
5. In *Titles*, click **Reset…** of `Reset this section to defaults`. **Expected:** a question naming
   "Titles", buttons `Reset` and `Cancel`, the focus on **Cancel**. Press Enter: nothing changes (Skill
   titles still on). Click Reset… again, then **Reset**: the *Skill titles* switch is off, no gear.
6. Click the **bug icon**. **Expected:** the notice `Debug info copied.` Paste it into any text field
   *outside* the vault (e.g. TextEdit): lines `Game Card Creator 0.7.0-m12.1`, `Obsidian <a version>` (Obsidian's API version; not assumed equal to the app's 1.15.0 — note what it shows), `Enabled
   plugins:` with `- game-card-creator 0.7.0-m12.1` and `- obsidian2typst …`, `Settings file:` and the
   settings as text. Close the settings window.

**Block C — the run dialog and the entry points (AC-1 to AC-6, AC-11)**

7. Command palette: **`Create cards from the saved selection`**. **Expected:** the notice `Nothing selected
   yet. Open "Create cards…" and choose notes.` Nothing is written.
8. The left ribbon: a grid icon with the tooltip **`Create cards…`**. Click it. **Expected:** a dialog
   titled `Create cards`: one row with the folder field (`…/M12 Out`), `Choose folder…` and a **disabled**
   `Create cards`; under it the grey line `Cards cards.pdf will be created.`; a `More options` button. Beside
   the dialog, a panel `Notes` with `Select all`, the tree with **every folder collapsed**, and `Save
   selection`.
9. In the panel, open `M12 Skills`: *Arrow Rain*, *Parry Drill*, *Reed Sweep* with the tag `skill`, and the
   folder `Sub`. Open `M12 Notes`: *Loose Idea* and *Session Log* **greyed**, tagged `no card kind`, their
   checkboxes cannot be ticked.
10. In the folder field, select all text and type `relative`. **Expected:** the red line `Output folder
    "relative" is not an absolute path`, the grey line empty, `Create cards` disabled. Undo (Cmd+Z, or type
    the path again) until the folder is `…/M12 Out` and the red line is gone.
11. Tick **`Select all`**. **Expected:** every note with a kind ticked, `Create cards` enabled. Untick the
    folder `Sub` inside `M12 Skills`: `Sub` and its two notes unticked, `M12 Skills` shows a **dash**
    (partly ticked).
12. Press **Escape**. The dialog and the panel close. Open the dialog again with the command palette
    **`Create cards…`**. **Expected:** nothing ticked (Cancel saved nothing), `Create cards` disabled.
13. Tick `Select all`, click **`Save selection`**. **Expected:** the notice `Selection saved.` Press Escape.
    Command palette: **`Create cards from the saved selection`**. **Expected:** the notice `✅ Created 8 cards
    on 1 page, 0 warnings. Written to …/M12 Out`; in `M12 Out`: `Cards cards.pdf` (rehearsal **22 002
    bytes**) and `Cards cards warnings.md` (`No warnings.`).
14. Click the ribbon icon. **Expected:** `Select all` already ticked (the saved selection); the grey line
    `Cards cards.pdf exists (from <today, the time of step 13>) and will be replaced after a question.` Click
    into the folder field and press **Enter**. **Expected:** the dialog closes; the replace question names
    both files, the focus on **Cancel**. Press Enter. **Expected:** the notice `❌ Card run cancelled.`;
    `M12 Out` unchanged.
15. Open the dialog. Untick `M12 Skills` (only the three spells stay ticked). Click **`Create cards`**, then
    **Replace**. **Expected:** `✅ Created 3 cards on 1 page, 0 warnings. Written to …/M12 Out`;
    `Cards cards.pdf` now **16 742 bytes** (rehearsal).
16. In the file explorer, rename `M12 Spells/Thin Breeze` to **`Thin Breeze II`**. Command palette:
    `Create cards from the saved selection`, then **Replace**. **Expected:** again `✅ Created 3 cards on 1
    page, 0 warnings …` (the renamed note stayed in the saved selection).
17. Open the dialog, click **`More options`**. **Expected:** the dialog closes and the settings open on the
    Game Card Creator tab.
18. *(Optional, needs an input method with composition, e.g. Japanese.)* Open the dialog with three notes
    ticked; in the folder field start a composition and press Enter to confirm a character. **Expected:** the
    character is confirmed, the dialog stays open, no run.

**Block D — end**

19. Send which steps passed and what differed. **Quit Obsidian.** The developer then reads the disk against
    the steps (`M12 Out`, the settings file), keeps the outputs, puts the vault back to
    `spikes/m12-before.txt` and proves it (SCAR-015, SCAR-018).

## Results

Run by the owner 2026-11-17 on build `0.7.0-m12.1` (M1 MacBook, macOS 27.0.1, Obsidian 1.15.0).

- Steps 1, 2, 4 to 13, 15 to 17 **passed**. Step 18 (optional) not reported.
- **Step 3 — the step was wrong (developer's error), not the build:** a card width of 10 is refused by the
  commit (US-007 AC-3: the last valid value stays), so the tab can never reach "Not ready" this way; the owner
  saw 62 kept. The rule "the tab opens the section with a problem" (AC-7) stays **unchecked in Obsidian**;
  the owner chose not to re-check it now (covered by its unit tests only). Disk: `sheet` absent from
  `data.json` (never saved).
- **Step 14 — finding F1 (defect, SCAR-014):** the replace question, opened after a run started with Enter in
  the dialog's folder field, showed the **focus ring on Replace**, and **Enter replaced the cards**
  (owner). Expected: focus on Cancel, Enter cancels (US-005 AC-7). The question focuses Cancel in its
  `onOpen`; something moves the focus afterwards: not measured. The same question kept Cancel focused in
  step 5 (opened by a click). M01 left this question's focus/Escape/Enter open (step 5): possibly older than
  US-013 and on every run started from the keyboard; not measured.
- Disk read against the steps (SCAR-015): `M12 Out` holds step 16's output: `Cards cards.pdf` 16 819 bytes,
  `No warnings.`; a rehearsal with the renamed note gives exactly 16 819 (the longer title); the saved
  selection is the three spells with `Thin Breeze II.md` (rename followed); *Skill titles* back to off, 9.1,
  7 (reset). Step 13's and 15's PDFs were replaced by later steps (sizes not read).

### Result of the diagnosis (owner 2026-11-17; the ring per step noted inline above, the log below read by the developer)

- In **all four paths** (D2 to D5) the log shows the same order: right after `onOpen` focuses the safe button the
  active element is **Cancel** (+0 ms); within 0 to 1 ms, before one tick, a `focusin` on **Replace** (in the
  question); Replace stays focused at one tick, one frame, 100 ms and 400 ms. Nothing of the plugin focuses
  Replace: **Obsidian's `Modal.open()` focuses the first focusable element after `onOpen` has run** (measured
  on Obsidian 1.15.0).
- The **ring** differs by path (keyboard D2, D4: ring on Replace; mouse D3, D5: no ring), **the focus does
  not**: in every path Enter would have replaced. D5 is the file-explorer path of 0.1.0 to 0.6.0: **F1 is
  older than US-013** (US-005 AC-7 has not held in Obsidian since 0.1.0; M01 step 5 had left it open).
- Escape cancelled in every path (it is decided apart from the focus).
- The reset question of the settings tab uses the same `confirmDialogWith`, so it is affected as well; M12
  step 5's "Enter: nothing changes" does not fit this cause and is re-checked with the fix.
- The `OUTSIDE question` lines are the trace's own listeners of earlier questions (kept 30 s): noise.
