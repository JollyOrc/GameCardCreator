# M05 — The deck note in the context menu, and the re-check of M04 step 9 (US-005 AC-9, D7)

Part of the [manual checks](../manual-checks.md).

**When:** after ticket #20, on a test build; and after any change to the menus.

**Needs:** Obsidian desktop (the author's default environment), the scratch vault with the test
build installed. Prepared by the developer (SCAR-012): the build installed with the checksums of
the installed files equal to the fresh build's (hand-over note); the plugin's `data.json` as the
M04 run left it (output folder inside the vault, `Exports`), its checksum recorded; the vault's
notes unchanged. Restart Obsidian once so the build is loaded. The developer waits for the
tester's "go" after each block of steps.

**Expected version:** the version in the hand-over note (the plugin's entry in Community plugins).
If it differs, stop: the wrong build is installed.

**Not assumed (SCAR-024):** which menus of Obsidian show the item. The story says "wherever
Obsidian fires `file-menu`"; this check records where it does.

## Steps

1. Right-click the note `Decks/Opening Deck.md` in the file explorer. **Expected:** two items,
   `Create cards` and below it `Create cards from this deck note`. Report what you see.
2. Click `Create cards from this deck note`. **Expected:** the same as the command `Create cards
   from this deck note`: if the files exist, the question with `Replace` and `Cancel`, the focus on
   `Cancel`; with `Replace` the PDF has the cards of the links of the note. Report the notice.
3. Right-click the note `Skills/Combat/Reed Sweep.md` and choose `Create cards` (the first item):
   **Expected:** one card for that note; the files are `Cards cards.pdf` and `Cards cards
   warnings.md` (US-005 AC-6: a single chosen note, unlike a folder, is named `Cards`).
   *Corrected 2026-11-12: the first text expected `Reed Sweep cards`, which is not the rule.*
4. Right-click the folder `Skills`, then select two notes with the Shift key and right-click:
   **Expected:** only `Create cards` in both. Right-click the picture `pics/…` file: report the
   items (only `Create cards` is expected).
5. **Other menus.** Open the note and right-click its **tab header**; open the editor's **more
   options** (the three dots) menu; right-click inside the note. For each, report whether the two
   items appear, one, or none. (The story does not promise these; this records what Obsidian does.)
6. **Re-check of M04 step 9 (finding F1, fixed).** Settings, Game Card Creator, `Choose folder…`,
   choose the vault's own folder (`spikes/m01-vault`): **a red message stays under the field**
   (`Output folder "…" is the vault's own folder`), the chosen path is shown in the field, and when
   you leave the page and come back the stored value is the old one. Do the same with the vault's
   `.obsidian` folder, then choose a valid folder to restore a good setting.
7. Is anything missing, odd or ugly that this list did not ask about? Report it even if it seems
   unrelated (SCAR-015).

**The developer's undo (SCAR-018):** `data.json` is restored from `spikes/data.json.m01.bak` by
checksum and the screen's backup file removed after this check closes M04; the vault's notes are
compared with the checksum list.
