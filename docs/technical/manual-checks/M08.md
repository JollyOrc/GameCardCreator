# M08 — The glyph check in Obsidian: a warning for a character no font draws (US-010 AC-1 to AC-6)

Part of the [manual checks](../manual-checks.md).

**When:** after ticket #39 on a test build; and after any change to the glyph check, the compile worker's
`font-info` message, or the fonts a creature run hands to the compile.

**Needs:** Obsidian desktop (the author's default environment) and a PDF viewer. Prepared by the developer
(SCAR-012, SCAR-018): the scratch vault of Obsidian2Typst
(`~/Documents/Obsidian2Typst/spikes/typst-wasm/scratch-vault`) with **Obsidian2Typst 0.15.2** (the release
build, byte-equal to its release files; preset `Cards M29`, whose fonts folder `Layouting/Fonts` holds DejaVu
Sans, which draws `✓`, `⌘` and `😀`, and Nimbus Roman) and the Game Card Creator test build `0.4.0-m08.1`;
the invented notes in `M08 Skills` (4) and `M08 Creatures` (1); the plugin's `data.json` (rules: `M08 Skills`
skill, `M08 Creatures` creature; output folder `M08 Out` inside the vault); the starting state in
`spikes/m08-before.txt` (315 files, `workspace.json` left out, written with null-separated names and checked
before any change) and the files changed or written by the plugins in `spikes/m08-state-backup/files/`
(including both plugins' `data.json`, which they rewrite while they run). The developer waits for the
tester's "go" after each block of steps. **Restart Obsidian once** so both plugins are loaded.

**Expected versions:** Game Card Creator `0.4.0-m08.1`, Obsidian2Typst `0.15.2` (Settings, Community
plugins). If either differs, stop: the wrong build is installed. Each step was walked through before the
handover against the code and the earlier checks, because Obsidian itself cannot be driven from the
developer's side: the commands used are the folder menu entry `Create cards` of M06 and M07; no setting has
to be changed; the notes and the plugin's `data.json` are in place.

**Not assumed (SCAR-024, SCAR-045):** how long the first run takes inside Obsidian with the new coverage
request (measured in Node: the driver starts in about 60 ms, the font files take 5 to 25 ms), and that the
real worker of Obsidian answers `font-info` for the plugin's own fonts and for the creature run's extra
fonts. The expected warnings and the skills PDF's size come from a rehearsal with the real worker code and
the vault's own font files in Node (SCAR-019); the creature card's statblock is drawn by the real
Obsidian2Typst, so its size is not given. What Obsidian shows is what this check records.

## Steps

1. Settings, Community plugins: **Game Card Creator `0.4.0-m08.1`** and **Obsidian2Typst `0.15.2`**.
2. Right-click the folder `M08 Skills`, choose `Create cards`. Note roughly how long it takes (the first
   run starts the compile worker). **Expected notice:** `4 cards on 1 page, 3 warnings. Written to …/M08 Out`.
   Files: `M08 Out/M08 Skills cards.pdf` (rehearsal: **15 397 bytes**) and `M08 Skills cards warnings.md`.
3. Open `M08 Skills cards warnings.md`. **Expected, exactly three lines** (in this order: the cards are in
   the order of the file names):
   - `SKILL_GLYPH_MISSING — M08 Skills/Han.md — 漢 U+6F22, 😀 U+1F600`
   - `SKILL_GLYPH_MISSING — M08 Skills/Many.md — 一 U+4E00, 丁 U+4E01, 丂 U+4E02, 七 U+4E03, 丄 U+4E04, 丅
     U+4E05, 丆 U+4E06, 万 U+4E07, 丈 U+4E08, 三 U+4E09 and 2 more`
   - `SKILL_GLYPH_MISSING — M08 Skills/Tick.md — ⌘ U+2318, ✓ U+2713`

   `Clean.md` has no line. Report anything that differs (a missing line, an extra one, another order).
4. Open the PDF (one page, four cards: Clean, Han, Many, Tick). **Expected:** *Clean* shows every character
   (`Привет → ★ ◆ ß é`); in *Han* the `漢` and the `😀` are **empty boxes** (the font's replacement glyph), in
   *Many* twelve boxes, in *Tick* a box each for `⌘` and `✓`. Look at the Han card at **printed size and at
   400 %** (SCAR-025): the boxes are where the warning says the missing characters are.
5. Right-click the folder `M08 Creatures`, choose `Create cards`. **Expected notice:** `1 card on 1 page, 1
   warning`. The warnings file has **one line**: `CREATURE_GLYPH_MISSING — M08 Creatures/Fen Hare.md —
   漢 U+6F22`. Not `✓`, not `😀`: the preset's DejaVu Sans, which the creature run hands to the compile,
   draws them.
6. Open that PDF. **Expected:** in the Behaviour section `flee at the first sound ✓` shows a **check mark**; in
   the Signs section `Flattened reeds in a ring` is followed by an **empty box** (the `漢`) and a **smiley**
   (the `😀`, drawn from DejaVu Sans). If `✓` or `😀` is a box here, the extra fonts did not reach the compile:
   report it.
7. Run step 2 again (answer `Replace`). **Expected:** the same notice, the same three lines, the same PDF size
   (15 397 bytes). Report both times (first and second run): the second should not be noticeably slower than
   a run before this build was used.
8. Settings, Community plugins: switch **Obsidian2Typst off**. Run `M08 Skills` again: **expected** the same
   notice and the same three warnings (a skills run does not need the other plugin). Switch it on again.
9. Is anything missing, odd or ugly that this list did not ask about? Report it even if it seems unrelated
   (SCAR-015).

**The developer's undo (SCAR-018):** the vault is compared with `spikes/m08-before.txt`; the files this check
added are removed (the folders `M08 Skills`, `M08 Creatures`, `M08 Out`, `.obsidian/plugins/game-card-creator/`
with the plugin's own `data.json` and any backup file it wrote) and the files it changed are restored from
`spikes/m08-state-backup/files/` (the Obsidian2Typst `main.js`, `manifest.json`, `styles.css`, `data.json`,
and `community-plugins.json`). Obsidian's own `workspace.json` may change and is ignored; a file the run
left that the list does not know is reported, not guessed.

MacBook, macOS 27.0.1, Obsidian 1.15.0): author: "M08 passes, times too quick to measure". The step-by-step
answers were not itemised; the developer read the disk afterwards (*disk*).

  warnings file with exactly the three lines of step 3 (`Han.md`, `Many.md`, `Tick.md`; none for `Clean.md`).

  exactly one line, `CREATURE_GLYPH_MISSING — M08 Creatures/Fen Hare.md — 漢 U+6F22`: not `✓`, not `😀`.
- *Disk, steps 7 and 8:* the skills files are the ones of the last run and equal the first run's size (15 397
  bytes), so the repeated runs, with and without Obsidian2Typst, gave the same PDF.
- *Times (step 7, SCAR-045):* too quick to measure, the author's words: no noticeable cost of the coverage
  request in Obsidian's worker, first run or second.
- Not recorded: the look of the cards at 400 % (the author says the check passes). The plugin's `data.json` was
  not rewritten by the runs (equal to what the developer wrote).
