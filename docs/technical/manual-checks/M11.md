## Decided before the run (SCAR-020, SCAR-032)

- **M1:** if the 200-card run takes **under 2000 ms**, US-013 AC-13 stands (runs report by notice, no
  progress tab); at 2000 ms or more, AC-13 is replaced by a progress tab AC before Ready.
- **M2:** the side panel is used for the selection tree if it (a) shows beside the dialog, (b) scrolls to
  row 300, (c) takes typing, and (d) goes away with the dialog on Escape, on the X and on a click outside.
  Otherwise the tree goes inside the dialog, under the destination row (a story amendment).
- **M3:** if `openTabById` opens the Game Card Creator tab, the dialog's gear uses it; if it only opens
  the settings window, the gear opens that and the row's text names the tab; if `app.setting` is not
  available, the gear goes and the row says `Settings → Game Card Creator`. If the icon `layout-grid` is
  missing, another icon is chosen at G2.

## Steps

**Block A — the build**

1. Settings, Community plugins: **Game Card Creator `0.6.0-m11.1`**. Optional: open the developer console
   (`Cmd+Option+I`), tab *Console*, so the `GCC spike` lines can be copied later.

**Block B — M1, whole-run times**

2. Right-click the folder `M11 Run 50`, choose `Create cards`. **Expected:** the notice `50 cards on 6
   pages, … Written to …/M11 Out` and the notice `GCC spike M1 selection of 1 item(s): N ms`. This is the
   first run since Obsidian started, so N includes the compiler's start. **Note N.**
3. The same for `M11 Run 100` (`100 cards on 12 pages`). **Note N.**
4. The same for `M11 Run 200` (`200 cards on 23 pages`). **Note N.** Also note: did Obsidian stay usable
   while it ran (could you scroll a note)?

**Block C — M2, the side panel**

5. Command palette: `Spike: dialog with a side panel (M2)`. **Look:** a dialog titled `GCC spike M2: dialog
   with a side panel` and, beside it, a narrower panel with `Row 1`, `Row 2`, … and a field `panel field`.
   Answer: (a) is the panel beside the dialog, both fully visible? (b) can you scroll the panel to `Row
   300`? (c) can you type in both fields?
6. Click into `panel field`, press **Escape**. Answer: (d1) did the dialog close, and the panel with it?
   (A notice `GCC spike M2 Escape in the panel field` shows that the panel saw the key.)
7. Open it again (step 5). Close it with the **X**. Answer: (d2) is the panel gone too?
8. Open it again. **Click outside** both. Answer: (d3) did both close?

**Block D — M3, settings tab and icon**

9. The left ribbon: is there a grid icon (four squares) with the tooltip `GCC spike ribbon (M3)`? Click
   it: notice `GCC spike M3 ribbon icon clicked`.
10. Command palette: `Spike: open the settings tab (M3)`. **Expected:** notices `GCC spike M3 icon
    layout-grid: exists` and `GCC spike M3 openTabById(game-card-creator): called, …`, and the settings
    window opens. Answer: does it show the **Game Card Creator** tab?

**Block E — end**

11. Send the noted values and answers (or the copied `GCC spike` lines). **Quit Obsidian.** The developer
    then puts the vault back to `spikes/m11-before.txt` and proves it (SCAR-018).

## Results

Run by the owner 2026-11-17 on build `0.6.0-m11.1` (M1 MacBook, macOS 27.0.1, Obsidian 1.15.0). The owner:
"all tests behave as expected, the card creation is always too fast to time manually".

- **M2: passed** (a) to (d3) as expected: the panel beside the dialog, scrolls, takes typing, goes with the
  dialog on Escape, the X and a click outside. By the rule above: the selection tree goes in the side panel.
- **M3: passed:** the icon `layout-grid` exists and shows in the ribbon; `openTabById` opens the Game Card
  Creator tab. By the rule above: the dialog's gear uses `app.setting.open()` + `openTabById`.
- **M1, read from the disk (SCAR-015):** `M11 Out` holds the three PDFs and warnings files of the runs:
  `M11 Run 50 cards.pdf` 6 pages (63 765 bytes), `M11 Run 100` 12 pages (114 366), `M11 Run 200` 23 pages
  (214 160); every warnings file `No warnings.`; all six files written within the minute 10:58. Page counts
  equal the expected ones.
- **M1, the times** (the spike's console lines, copied by the owner while Obsidian still ran): `M11 Run
  50` **526 ms** (first run after the start: includes the compiler's start), `M11 Run 100` **149 ms**,
  `M11 Run 200` **274 ms**. By the rule above (200 cards under 2000 ms): **US-013 AC-13 stands**, no progress
  tab. Holds for skill cards on this machine; creature runs not measured.
- **M2, a finding beyond the rule:** the console has three `opened` / `closed` pairs (steps 5, 7, 8) but
  **no line `GCC spike M2 Escape in the panel field`**, although the dialog closed on Escape in step 6
  (owner: as expected). So Obsidian's modal handles Escape before the panel's field sees the key. For the
  story: Escape needs no handling in the panel (it closes the dialog anyway); **Enter in a panel field is not
  measured** and must not be assumed to reach the field's own listener (to be measured at G4 if the panel
  gets a field; the tree itself has no text field).
- Dialog height logged: 142 px (the spike's minimal dialog), so the panel was 284 px high.
