# M10 — Equal title bands on creature cards in Obsidian (US-012 AC-1 to AC-12)

Part of the [manual checks](../manual-checks.md).

**When:** after ticket #49 on a test build; and after any change to the equal title bands of creature cards,
the creature title fields of the settings screen, or the band of Obsidian2Typst's statblock.

**Needs:** Obsidian desktop (the author's default environment: M1 MacBook, macOS 27.0.1, Obsidian 1.15.0)
and a PDF viewer. Prepared by the developer (SCAR-012, SCAR-018): the scratch vault of Obsidian2Typst
(`~/Documents/Obsidian2Typst/spikes/typst-wasm/scratch-vault`) with

- **Obsidian2Typst 0.15.2**, the release files (`main.js` sha256 `0e7da7c4…`, checked), replacing the
  `0.15.1-m29.1` the vault held; its `data.json` unchanged (active preset `Cards M29`: no band font, so the
  band is set in Libertinus Serif);
- the Game Card Creator test build **`0.6.0-m10.1`** (installed by `npm run install:scratch`, checked against
  the fresh build by checksum; built from commit `b5fb07c`) and enabled in the plugin list;
- invented notes: `M10 Creatures` (six: *Fen Hare*, *Reedmother*, *Marsh Lantern Wisp*, *Old Grey Ferryman of
  the Sunken Weir*, *Thornwhisperingbramblequeen*, each with a statblock; *Weir Keeper* without statblock
  properties, so Obsidian2Typst refuses its statblock and the card draws its own title), `M10 Skills` (*Parry*,
  *Riverbank Ambush of the Reed Wardens*), `M10 Decks/Short Deck.md` (links to three creatures and both
  skills); every linked name is unique in the vault (listed at the preparation);
- the plugin's `data.json`: rules `M10 Creatures` creature, `M10 Skills` skill; output folder `M10 Out` inside
  the vault; everything else at its default, so every switch is **off**.

The starting state is `spikes/m10-before.txt` (315 files, `workspace.json` left out; 315 lines, all OK before
any change); the whole `.obsidian` folder (both plugins' `data.json` included) is in
`spikes/m10-state-backup/files/` (15 files, checksums `spikes/m10-state-backup/sums.txt`); the state after the
preparation is `spikes/m10-handover.txt`. Obsidian was not running during the preparation: **start Obsidian;
it opens the scratch vault** (the last one open). The developer waits for the tester's "go" after each block.

**Expected version:** Game Card Creator `0.6.0-m10.1` and Obsidian2Typst `0.15.2` (Settings, Community plugins).
If either differs, stop: the wrong build is installed. Each step was walked through against the code and the
earlier checks (Obsidian cannot be driven from the developer's side): the folder menu entry `Create cards` and
the note menu entry `Create cards from this deck note` of M06 and M07; the page `Page and text size` with the
title groups of M09; the `Replace` question of M01.

**Expected values** come from a rehearsal in Node with the plugin's own runner, its compile worker core
(typst.ts 0.7.0), these notes and settings, and Obsidian2Typst 0.15.2's real API with this vault's preset,
icons and fonts (its bundled fonts and the valid fonts of `Layouting/Fonts`, as Obsidian2Typst hands them
over); M07's and M08's PDFs had the same bytes or size in Obsidian as in their rehearsals. **Not assumed
(SCAR-024, SCAR-045):** how long a run takes in Obsidian (in Node, 200 creature cards in equal mode about
1.3 s; these runs have 5 and 6 cards).

## Steps

**Block A — today's look (every switch off)**

1. Settings, Community plugins: **Game Card Creator `0.6.0-m10.1`** and **Obsidian2Typst `0.15.2`**.
2. Right-click the folder `M10 Creatures`, choose `Create cards`. **Expected notice:** `6 cards on 1 page, 1
   warning. Written to …/M10 Out`. Files: `M10 Out/M10 Creatures cards.pdf` (rehearsal **61 541 bytes**) and
   `M10 Creatures cards warnings.md` with the one line `CREATURE_STATBLOCK_REFUSED — M10 Creatures/Weir
   Keeper.md — No statblock: no stats or attacks.`
3. Open the PDF. **Expected (today):** six cards in the order Fen Hare, Marsh Lantern Wisp, Old Grey Ferryman,
   Reedmother, Thornwhisperingbramblequeen, Weir Keeper. Five statblocks; their names at one size here (every
   card fits at 7 pt, so every band is 11.5 pt), but **the ferryman's band takes two lines** (its ◆ marks at
   the two ends, level with the middle of the name) and is taller than the others. *Weir Keeper* has no
   statblock: its own bold title and a rule under it.

**Block B — the switch on an open tab (AC-9, SCAR-016)**

4. Settings, Game Card Creator, `Page and text size`. **Expected:** after `Spell titles` a third group,
   `Creature titles`, with only the toggle `Equal title bars` (off). Keep this tab open until step 10.
5. Switch **`Creature titles` → `Equal title bars` on**. **Expected at once** (without leaving the page):
   under it `Title size` **11.5** and `Smallest title size` **7**; the skill and spell groups unchanged.
6. In `Title size` type `21` and press Enter. **Expected:** refused, under the field `The creature title size 21
   is outside 6 to 20 pt`. Type `11.5` again and press Enter: the message goes.

**Block C — one name size (AC-2, AC-3, AC-5, AC-12)**

7. Run `M10 Creatures` again (answer `Replace`). **Expected notice:** `6 cards on 1 page, 1 warning.` (the
   same warnings file as step 2). PDF: rehearsal **60 598 bytes**.
8. Open the PDF. **Expected:** **every name the same size** (7.75 pt: the size at which the ferryman's name
   fits on one line), smaller than in step 3; **every band on one line and equally high**, the ferryman's
   included; *Weir Keeper*'s own title at the same size. Look at the top row **at printed size and at 400 %**
   on the rule under each band (SCAR-025): the rules of the three cards lie on one line.

**Block D — too long at the smallest size; a hidden value kept (AC-4, AC-8, AC-9)**

9. On the open tab: `Smallest title size` `9`, Enter. Run `M10 Creatures` (`Replace`). **Expected:** `6 cards
   on 1 page, 2 warnings`; the warnings file's second line `CREATURE_TITLE_WRAPPED — M10 Creatures/Old Grey
   Ferryman of the Sunken Weir.md — 1 of 6 titles wrap at 9 pt`; PDF rehearsal **61 540 bytes**. In the PDF
   every name at 9 pt; the ferryman's band on two lines (taller, its marks at the ends), the other bands on one
   line and equally high.
10. Switch `Equal title bars` **off**: the two size fields vanish at once. Switch it **on** again: `Smallest
    title size` shows **9** (kept). Set it back to `7`, Enter.

**Block E — with skill cards, a non-default size (AC-8, AC-10)**

11. On the same page: `Skill titles` → `Equal title bars` **on** (its sizes stay 9.1 and 7); `Creature titles`
    → `Title size` **14**, Enter. Right-click `M10 Decks/Short Deck.md`, choose `Create cards from this deck
    note`. **Expected:** `5 cards on 1 page, 0 warnings`; `M10 Out/Short Deck cards.pdf` (rehearsal **47 907
    bytes**). In the PDF the three creature names at one size (13.75 pt, larger than in step 8), each on one
    line; the two skill titles at one size (8.1 pt) — each kind its own size.

**Block F — off again (AC-1)**

12. Switch **both** toggles off (`Skill titles` and `Creature titles`). Run `M10 Creatures` (`Replace`).
    **Expected:** the notice and the warnings file of step 2, and the PDF **61 541 bytes** again (today's
    cards exactly).
13. Is anything missing, odd or ugly that this list did not ask about? Report it even if it seems unrelated
    (SCAR-015).

**The developer's undo (SCAR-018):** the outputs are kept in `spikes/m10-out-kept/`; the vault is compared with
`spikes/m10-handover.txt` and `spikes/m10-before.txt`; the files this check added are removed (`M10 Creatures`,
`M10 Skills`, `M10 Decks`, `M10 Out`, `.obsidian/plugins/game-card-creator/` with its `data.json` and the
settings backup the screen writes on its first change); Obsidian2Typst's three plugin files, its `data.json`
and the plugin list are restored from `spikes/m10-state-backup/files/` (back to `0.15.1-m29.1`, the state the
vault was handed over in); any other `.obsidian` file that differs from the backup is restored from it.
Obsidian's own `workspace.json` may change and is ignored; a file the list does not know is reported, not
guessed. The result is checked against `spikes/m10-before.txt`: 315 of 315.

## Results

Build `0.6.0-m10.1` with Obsidian2Typst 0.15.2, the author's run of 2026-11-16, default environment: **"all tests
pass"**. The disk afterwards (kept in `spikes/m10-out-kept/`, checksums `spikes/m10-out-kept.sums`), read against the
steps:

- `M10 Creatures cards.pdf` (19:10:46) is step 9's: 61 540 bytes, byte-equal to the rehearsal with the smallest size
  9; its warnings file has both expected lines.
- `Short Deck cards.pdf` (19:13:04) is 47 941 bytes, not step 11's 47 907: byte-equal to a rehearsal of the deck with
  **both switches off** (a rehearsal with the smallest size 9 and the switches on gives 47 907, so that setting is not
  the cause). The settings file was last written at 19:12:53 with both switches off. Read: the deck was run again
  after the switches went off, replacing step 11's PDF; step 12's run of `M10 Creatures` left no file.
- The settings file still has the creature smallest size 9: step 10's reset to 7 was not saved (it changes neither
  run, measured for the deck).

Not visible on disk: steps 7, 11 and 12 (replaced or not written). The author's "all tests pass" covers what they
looked at; the off-state deck equals today's code, and step 9's PDF equals the rehearsal.

Asked afterwards, the author confirmed ("yes") that step 11's deck was run with both switches on and showed each
kind at its own size (creatures 13.75 pt, skills 8.1 pt).
