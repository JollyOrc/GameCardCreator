# M07 — Colour-coded headers and icons in Obsidian (US-009 AC-1, AC-2, AC-3, AC-4, AC-5, AC-6, AC-7, AC-8, AC-10, AC-11, AC-12, AC-14, AC-15)

Part of the [manual checks](../manual-checks.md).

**When:** after ticket #33, on a test build; and after any change to the band, the icons, the scheme note's
reader or its settings.

**Needs:** Obsidian desktop (the author's default environment), the scratch vault of Obsidian2Typst
(`~/Documents/Obsidian2Typst/spikes/typst-wasm/scratch-vault`) with **Obsidian2Typst 0.15.1** (the release
build) and the Game Card Creator test build. Prepared by the developer (SCAR-012, SCAR-018): the invented
notes in `M07 Skills` (5), `M07 Spells` (5), `M07 Scheme` (a good scheme of four rows and one with a bad
row), `M07 Decks` (a deck of four links), the plugin's `data.json` (rules: `M07 Skills` skill, `M07 Spells`
spell; output folder `M07 Out` inside the vault; scheme note `M07 Scheme/Good Scheme.md`), the starting
checksums in `spikes/m07-before.txt` (315 files, `workspace.json` left out) and the changed files in
`spikes/m07-state-backup/files/`. The developer waits for the tester's "go" after each block of steps.
**Restart Obsidian once** so both plugins are loaded.

**Expected versions:** Game Card Creator `0.3.0-m07.1`, Obsidian2Typst `0.15.1` (Settings, Community
plugins). If either differs, stop: the wrong build is installed.

**Not assumed (SCAR-024, SCAR-045):** that the icon font reaches the compile inside Obsidian (it is
embedded in the plugin and was proven in Node only), how the screen's new field and its line look, and that
the size of a PDF made inside Obsidian equals the one made in Node. The expected cards, warnings and sizes
below come from a rehearsal of the same notes and settings compiled in Node (SCAR-019); what Obsidian
shows is what this check records. The colours are invented; the author's own scheme comes after this
check (ticket #34).

## Steps

1. Settings, Game Card Creator, page `Note properties`, group `Scheme note`: **expected** one field `Scheme
   note` holding `M07 Scheme/Good Scheme.md` and, under it, the line `Scheme note: M07 Scheme/Good Scheme.md`.
   Change the value to `M07 Scheme/Nope.md`: **expected** the line `Scheme note: not found`. Change it back.
   Report how the field and the line look.
2. Right-click the folder `M07 Skills`, choose `Create cards`. **Expected notice:** `5 cards on 1 page, 1
   warning. Written to …/M07 Out`. Files: `M07 Out/M07 Skills cards.pdf` and `M07 Skills cards warnings.md`.
   Note roughly how long it takes (the first run builds the compiler).
3. Open the PDF. **Expected, one page, cards in the order of the file names:**
   1. *Long Parry:* a flat band `#F4D6B0` (pale orange) from the top edge across the card, the tags line
      `Swordplay`, the title and `Time: reaction` on it in black, **one sword icon at the right end**; the
      long text starts under the band and fits in full (14 sentences).
   2. *Parry:* the same band; tags line `Combat Skill · Swordplay`; one sword icon.
   3. *Plain:* **no band, no icon**: the plain header as before (tags `Misc`, the title with a line).
   4. *Spelling:* the same band as Parry (its tag is written `#swordplay ` with a space and no capital).
   5. *Stone Guard:* a **gradient** from pale blue-grey (`#CBD5E8`, left) to pale orange (`#F4D6B0`, right);
      two icons side by side: **anvil first, sword at the right edge**; tags line `Stonework · Swordplay`.
   Every band reaches the card's frame and the frame is drawn over it (no band outside the frame: the bleed
   is 0). At the foot of the page, centred, one small line: `Icons made by Lorc, Delapouite, sbed and other
   authors. Available on https://game-icons.net (CC BY 3.0), via RPG Awesome`. Report anything that differs.
4. Look at **printed size** (zoom 100 %, or print preview) and at **400 %** on the header of Stone Guard
   (AC-14, SCAR-025): the black text is easy to read over every colour, the icons are not clipped and do not
   touch the text, the gradient runs without a hard edge, the band ends a little under the last header line.
5. Open `M07 Skills cards warnings.md`. **Expected, one line:** `SKILL_BRANCH_UNKNOWN — M07 Skills/Plain.md —
   Misc`.
6. Right-click `M07 Spells`, `Create cards`. **Expected notice:** `5 cards on 1 page, 1 warning`. Cards
   (order of the file names): *Ember Spark* (flat salmon band `#FFB4A2`, fire icon); *Scorch Hex* (gradient
   salmon to light green `#E4F0A8`, fire then skull at the right edge); *Triple Fire* (gradient salmon,
   light green, blue-grey: the middle colour in the middle; fire, skull, anvil); *Ward Of The Old Grey
   Mountain Kings Hexed And Burning* (the same three icons; **the title wraps over three lines to the left of
   the icons** and the band is taller than the others, its tags line above); *Wild Notion* (no band;
   warning below). Warnings file: **one line** `SPELL_BRANCH_UNKNOWN — M07 Spells/Wild Notion.md —
   Divination`.
7. Right-click `M07 Decks/Mixed Deck.md`, `Create cards from this deck note`. **Expected:** `4 cards on 1
   page, 0 warnings`; Parry, Scorch Hex, Ember Spark, Triple Fire in that order; the credit line at the foot.
8. Settings, `Note properties`, `Scheme note`: set `M07 Scheme/Bad Row Scheme.md`. Run `M07 Skills` again
   (answer `Replace`). **Expected:** `5 cards on 1 page, 2 warnings`; the warnings file starts with
   `SCHEME_ROW_INVALID — M07 Scheme/Bad Row Scheme.md — line 10: unknown icon "no-such-icon"`, then the
   `Plain` line; *Stone Guard* now has **only the sword and a flat band** (the Stonework row is refused);
   the credit line is the default text (that note has no `credit`), the same text as before.
9. Set `M07 Scheme/Missing.md`. **Expected:** the line `Scheme note: not found`; run `M07 Skills`:
   `5 cards on 1 page, 1 warning`, the warning `SCHEME_NOTE_UNREADABLE — M07 Scheme/Missing.md — Cannot
   read M07 Scheme/Missing.md: it is not a file of the vault`; **all five cards have plain headers**, no
   credit line. Then clear the field (empty): run again: `5 cards on 1 page, 0 warnings`, the same plain
   cards. (The two PDFs of this step are the same bytes, 17 626 in the rehearsal.)
10. Set the scheme note back to `M07 Scheme/Good Scheme.md`. Settings, page `Layout`, group `Sheet`: set
    `Bleed` to `1` (cut marks stay on). Run `M07 Skills`. **Expected:** the same cards; the bands of Long Parry and Parry (the first row) reach 1 mm above the top edge; Long Parry's and Spelling's bands reach 1 mm left of the card; **Stone Guard's band reaches 1 mm
    beyond its right edge** (nothing is to its right); **between neighbouring cards and under another card
    there is no bleed** (the gap is 0); the text has not moved. Set `Bleed` to `2`: **expected** a red message
    (above 1 mm, the distance of the cut marks) and nothing saved. Set `Bleed` to `0` again.
11. Is anything missing, odd or ugly that this list did not ask about? Report it even if it seems unrelated
    (SCAR-015).

**Expected PDF sizes of the rehearsal (Node, same notes and settings):** step 2 `22 369` bytes; step 6 `25 137`;
step 7 `22 870`; step 8 `21 687`; step 9 `17 626`; step 10 `22 405` (bleed 1, cut marks on). A different size
is not a failure by itself (report it), a different look is.

**The developer's undo (SCAR-018):** the vault is compared with `spikes/m07-before.txt`; the files this check
added (the folders `M07 *`, `.obsidian/plugins/game-card-creator/`, the plugin's line in
`community-plugins.json`, the Obsidian2Typst files changed from `0.15.1-m29.1` to the release's) are
removed or restored from `spikes/m07-state-backup/files/`. Obsidian's own `workspace.json` may change and is
ignored.
