# Game Card Creator v0.4.0

**Release date:** 2026-11-17

A warning when a card's text has a character that no font draws. Nothing else changes: a run in which every
character is drawn gives the same warnings and the same PDF as 0.3.0. Desktop only.

## Features

- **The glyph check** (US-010, backlog #5): the compiler draws a character that no font has as an empty
  box and gives no diagnostic. For every card the plugin now reads the text it sets (the title, the tags, the
  details row and the note's text of a skill or spell card; the title when there is no statblock, the headings
  and the texts of the sections of a creature card), asks the compiler which characters the fonts of the compile
  cover, and gives **one warning per note**: `SKILL_GLYPH_MISSING`, `SPELL_GLYPH_MISSING` or
  `CREATURE_GLYPH_MISSING`, the note's path, and the characters in code point order with their code points
  (`漢 U+6F22, 😀 U+1F600`), ten at most and then `and N more`.
- **A character that some font of the compile draws is not reported:** the check reads the fonts the compile
  really has, the plugin's own (Libertinus Serif and the icon font) and, on a creature sheet, the fonts that
  Obsidian2Typst hands over (its preset's fonts folder). Example: a `✓` or a `😀` in a creature note is drawn
  by the preset's DejaVu Sans and gives no warning; a `漢` is drawn by none and does.
- **Not checked:** spaces, control, zero-width and direction characters and variation selectors; the
  statblock's own text (it is Obsidian2Typst's); the credit lines at the foot of a sheet.
- **When the fonts' coverage cannot be read** the run goes on without the check and gives one warning,
  `GLYPH_CHECK_UNAVAILABLE`, with the reason.
- The warnings stand after the notes' own warnings and before the fit warnings; the notice's count and the
  warnings file include them in their usual form.

## Changed behaviour

None for notes whose characters are all drawn. The PDF of a card with a missing character is as before (the
empty box stays).

## Known limits

- **Tested on:** Obsidian 1.15.0 on macOS (Apple silicon), in a scratch vault with Obsidian2Typst 0.15.2
  (manual check M08: a skills folder and a creature folder; the times were too quick to measure). **Not
  tested:** Windows, Linux, mobile, other Obsidian versions, your own vault's notes. `minAppVersion` stays
  1.6.6.
- The check looks at code points: a letter written as a base letter plus a combining mark is checked as two
  characters; a font that covers each but draws the combination badly is not detected.
- No picture on the creature card: won't do (US-006). Equal title bars are a backlog item (#35).
- `main.js` is about 15.8 MB (the compiler and two fonts are inside it).
