# Game Card Creator v0.6.0

**Release date:** 2026-11-16

Equal title bands for creature cards: one name size for every creature card of a run, as 0.5.0 gave skill and
spell cards one title size. With the new switch off, creature cards are as in 0.5.0. Desktop only.

## Features

- **Equal title bands on creature cards** (US-012, the follow-up of US-011): a third group, `Creature titles`, on
  the page `Page and text size`, with the switch `Equal title bars`, `Title size` (default 11.5 pt, Obsidian2Typst's
  own band size; 6 to 20) and `Smallest title size` (default 7 pt, 4 to the title size), shown while the switch is
  on. With the switch on, every creature card of the run gets **one name size** in its statblock band: the largest
  size, from the title size down to the smallest in steps of the text size step, at which every name stays on one
  line. The name no longer shrinks with a card's text; the rest of the statblock still does.
- One line is decided by drawing the band with Obsidian2Typst's own statblock (its ◆ marks included), so the cards
  follow the statblock's rules without a copy of them; the widest name is measured in the band's own font.
- A creature card without a statblock (refused by Obsidian2Typst) sets its own title at the same size, and counts
  in the size.
- **A name too long even at the smallest size** takes two lines in its band, the other bands keep one, and the run
  gives one warning, `CREATURE_TITLE_WRAPPED`, naming the note with the widest name: `1 of 6 titles wrap at 9 pt`.
  (An equal band height for such a name would need a new input of Obsidian2Typst; not made.)
- Skill and spell cards are not changed; each kind has its own size.

## Changed behaviour

None with the switch off: a run gives the same Typst source as 0.5.0.

## Fixes

None.

## Breaking changes and migration

None. A settings file of 0.5.0 reads as before; the new settings take their defaults (the switch off).

## Known limits

- **Tested on:** Obsidian 1.15.0 on macOS (Apple silicon) with Obsidian2Typst 0.15.2, in a scratch vault (manual
  check M10: the switch on an open tab, a refused size, one name size, a card without a statblock, a name too long
  even at the smallest size, a deck with skill cards). **Not tested:** Windows, Linux, mobile, other Obsidian
  versions, your own vault's notes. `minAppVersion` stays 1.6.6.
- Equal mode measures every name of the run once; in Node, 200 creature cards took about 1.3 s with it on against
  about 1.5 s off.
- The text under the statblock does not start at one height on every card: the statblocks differ (boxes, track,
  lines).
- `main.js` is about 15.8 MB (the compiler and two fonts are inside it).
