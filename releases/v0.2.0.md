# Game Card Creator v0.2.0

**Release date:** 2026-11-13

The creature card. It needs the plugin Obsidian2Typst 0.15.1 or newer (installed and enabled);
skill and spell cards work without it, as before. Desktop only.

## Features

- **Creature card** (US-004): the statblock exactly as Obsidian2Typst draws it for a book, taken
  through that plugin's API (its preset, icons and fonts, the preset's credit text), then the
  creature's **Behaviour**, **Actions** and **Signs** sections, each with a small bold heading. The
  statblock's sizes follow the card's text size.
- **When it does not fit** the card gives up the Signs section first, then Behaviour, then the
  Skills line of the statblock, each time at the largest text size again; only then does the text
  shrink, and it is cut with a warning at the smallest size. A given-up Behaviour section or
  Skills line is reported (`CREATURE_PART_DROPPED`), a cut text too (`CREATURE_TEXT_OVERFLOW`).
- **Sections are found by their heading** (case ignored, at any level; a heading inside a callout or a
  list is not a section heading). A missing Behaviour or Actions section is reported
  (`CREATURE_SECTION_MISSING`), a missing Signs section is not.
- **The credit** of the icons is printed once at the foot of each sheet that has a creature card
  (5 pt, centred, at most two lines); if the bottom margin is too low for it the plugin says so
  (`CREATURE_CREDIT_OMITTED`).
- **Settings:** a rule kind `creature` for the folder rules, and the three section headings
  (`Instincts heading`, `Actions heading`, `Signs heading`, default `Behaviour`, `Actions`,
  `Signs`) on the page `Note properties` of the settings screen.
- **A creature whose statblock Obsidian2Typst refuses** (no stats or attacks) gets a card without a
  statblock and a warning (`CREATURE_STATBLOCK_REFUSED`); the warnings of Obsidian2Typst's own data
  checks are passed on unchanged (for example `STAT_SUM_MISMATCH`).
- **Without Obsidian2Typst** (not installed, not enabled, or older than 0.15.1) no creature card is
  made, the other cards are, and the run says why (`CREATURE_API_UNAVAILABLE`).

## Changed behaviour

- A compile that is given files or fonts for one run (the creature card) uses them for that run only;
  the next run is as before.
- The notice of a run that has no card to print names the reason when it is a missing Obsidian2Typst.

## Fixes

- **A largest text size equal to the smallest** (allowed by the settings) made every card kind fail
  to compile (the list of sizes was written as a number). Fixed for skill, spell and creature cards.

## Breaking changes and migration

None. To make creature cards: install Obsidian2Typst 0.15.1 or newer, give Obsidian2Typst a preset
with a statblock setup (the one you use for your book), add a folder rule of the kind `creature`.

## Known limits

- **Tested on:** Obsidian 1.15.0 on macOS (Apple silicon), in a scratch vault with Obsidian2Typst
  0.15.1 (manual check M06). **Not tested:** Windows, Linux, mobile, other Obsidian versions, your own
  vault's data (the first run on a real vault is the owner's). `minAppVersion` stays 1.6.6.
- No picture on the creature card (US-006). Backlog #5: no warning yet when a card's text has a
  character the font lacks.
- A creature compile builds a compiler with the book's fonts the first time (measured in Node, not
  timed separately in Obsidian); the compiler is kept while the same fonts come again.
- `main.js` is about 15.6 MB (the compiler is inside it).

## Stories and issues

US-004. Tickets #21 to #27 (closed). Obsidian2Typst 0.15.1 (its US-040) is the version that numbers
the icon files by the preset's track order, which this plugin relies on.
