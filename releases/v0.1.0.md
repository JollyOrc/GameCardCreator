# Game Card Creator v0.1.0

**Release date:** 2026-11-12

The first release. Skill and spell cards from the notes of a vault, as an A4 PDF to print and
cut. Desktop only.

## Features

- **Cards of 62 x 88 mm on an A4 sheet** (US-001): as many cards per page as fit inside the
  margin (3 x 3 by default), with cut marks; the card size, margin and gap are settings.
- **Skill card** (US-002) and **spell card** (US-003): the tags of the note, its title, a labelled
  details row for skills (`Time`, `Type`, `Requires`), and the full text of the note; no pictures
  (an image in a note is left out with a warning). The text shrinks from the largest size (7 pt)
  towards the smallest (5.5 pt) and is cut with a warning if it still does not fit.
- **Make cards from notes** (US-005): from a **deck note** (a list of links to the notes, in the
  order of the links) with the command `Create cards from this deck note`, or from the **file
  explorer's context menu**: `Create cards` for one or several notes or folders, and `Create cards
  from this deck note` for a single note (also in a note's tab menu and the editor's menu). The
  kind of a note (skill or spell) comes from folder rules. The result is `<name> cards.pdf` and a
  warnings file `<name> cards warnings.md` in the output folder; an existing result is replaced
  only after a question.
- **A settings screen** (US-007): the output folder (typed or chosen in the system's folder
  dialog), the kind rules (with the vault's folders suggested), the property names and labels, the
  sheet and the text sizes; invalid values are refused with the reason under the field; a status
  line says whether the plugin is ready. The first save keeps a copy of an existing `data.json`.
- **Nothing to download or install:** the Typst compiler and the font (Libertinus Serif, SIL OFL)
  are inside `main.js` (US-008); a compile makes no network request.

## Known limits

- **No creature card yet** (US-004); no pictures on cards (US-006). Backlog #5: no warning yet when
  a card's text has a character the font lacks.
- **Tested on:** Obsidian 1.15.0 on macOS (Apple silicon), in the author's vault and in a generated
  scratch vault. **Not tested:** Windows, Linux, mobile (the plugin is desktop only), other
  Obsidian versions. The minimum version in `manifest.json` (1.6.6) is the highest `@since` of the
  Obsidian APIs the plugin uses, read from their type definitions; it was **not run** on 1.6.6.
- The size of `main.js` is about 15.6 MB (the compiler is inside it); the first card run in a
  session takes a moment (about half a second measured on the author's machine) because the
  compiler starts then.
