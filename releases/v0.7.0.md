# Game Card Creator v0.7.0

**Release date:** 2026-11-17

A run dialog with a note picker, a ribbon icon and two new commands; the settings in collapsible sections;
clearer notices. And a fix that matters: the question before replacing cards now really starts on **Cancel**
in Obsidian. Desktop only.

## Features

- **Run dialog** (`Create cards…`, from the new ribbon icon or the command palette): the output folder with
  `Choose folder…` and a `Create cards` button in one row; a red line says why a folder is refused (the button
  stays disabled), a grey line says what is there (`Cards cards.pdf will be created.`, or that it exists, with its
  date, and will be replaced after a question). Beside the dialog, a panel with the vault's notes as a tree:
  `Select all`, folders collapsed, each note's card kind as a tag, notes without a kind greyed. `Save selection`
  keeps the choice; with every note with a kind ticked it is saved as *all*, so notes added later are included.
  Enter runs when the button is enabled; Escape closes without saving anything. `More options` opens the plugin's
  settings.
- **`Create cards from the saved selection`**: runs the saved selection at once, without the dialog.
- The saved selection **follows renames and deletes** of notes and folders.
- **Settings in collapsible sections**: *Output*, *Which note is which card*, *Note properties*, *Page and text
  size*, *Titles*. The first section with a problem opens first. *Titles* shows one row per card kind with the
  `Equal title bars` switch and a gear (shown while the switch is on) that opens the two sizes. Each section with
  defaults has `Reset this section to defaults`, behind a question.
- **Copy debug info** (bug icon at the top of the settings): copies the plugin's and Obsidian's versions, the
  settings file and the enabled plugins to the clipboard, for a bug report. Nothing is sent.
- The deck note menu entries and the command `Create cards from this deck note` stay as they were.

## Changed behaviour

- **Notices:** a finished run reads `✅ Created 12 cards on 2 pages, 3 warnings. Written to …`; Cancel at the
  replace question now says `❌ Card run cancelled.` (before: nothing); a failed run and a run that gives no PDF
  read `❌ Card run failed: …`. A refused run names the settings section to fix (`See Settings → Output (file:
  …)`).
- **The settings screen** has no sub pages and no `Back` any more; the page resets became section resets.
  Resetting *Page and text size* no longer resets the title sizes (they are the *Titles* section now).
- The replace and reset questions show **`Cancel` first**, then `Replace` / `Reset`.

## Fixes

- **The replace question started on Replace in Obsidian** (#58): the plugin put the focus on Cancel, but
  Obsidian moves the focus to a dialog's first button right after it opens. So Enter replaced the cards, since
  0.1.0; the focus ring only showed after keyboard input. Cancel is now the first button, and Enter cancels. The
  reset question had the same defect.

## Breaking changes and migration

None. A settings file of 0.6.0 reads as before; a saved selection is new and absent until you save one.

## Known limits

- **Tested on:** Obsidian 1.15.0 on macOS (Apple silicon), in a scratch vault (manual checks M11: the dialog
  layout, the settings tab opened by its id, run times; M12: every entry point, the dialog, the tree, the
  sections, the notices, and the re-check of the fix by keyboard and by mouse). **Not tested:** Windows, Linux,
  mobile, other Obsidian versions, your own vault's notes; the opening of the section with a problem was not
  checked in Obsidian (it is covered by tests); typing with an input method that composes characters was not
  checked in Obsidian.
- Run times measured: 200 skill cards in 274 ms (no progress display needed); creature cards not measured.
- `minAppVersion` stays 1.6.6. `main.js` is about 15.8 MB (the compiler and two fonts are inside it).
